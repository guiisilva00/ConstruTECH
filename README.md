## 📌 Overview - ConstruTECH

O **ConstruTECH** é um sistema web intuitivo voltado para o gerenciamento de estoque e controle de insumos na área da construção civil. Projetado para atender administradores de depósitos e gestores de materiais, o sistema simplifica o acompanhamento em tempo real das quantidades de itens, cálculo de totais investidos e cadastros do catálogo, garantindo eficiência operacional e controle financeiro dinâmico por meio de uma interface organizada e segura.

### ✨ Principais Destaques

* **Controle Dinâmico de Estoque:** Gestão simplificada de insumos com suporte a filtros de busca, incrementos e decrementos rápidos de quantidades, além de alertas visuais para níveis baixos de material.
* **Autenticação Segura:** Sistema de login com validação de dados em sessão e controle de acessos restritos ao painel administrativo (Dashboard).
* **Cálculo Automatizado de Investimentos:** Processamento automático do valor total investido por item e balanço geral do inventário cadastrado.
* **Interface Responsiva e Temática:** Layout moderno e amigável desenvolvido com HTML5, CSS3 personalizado e tipografia *Inter* otimizada para uso diário.

### 🛠️ Tecnologias Utilizadas

* **Backend:** PHP (Sessões e integração com PDO/MySQL).
* **Database:** MySQL.
* **Frontend:** HTML5 e CSS3.
